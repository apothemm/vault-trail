# Архитектура

CLI → валидация команд → snapshot / diff / verify / restore.

`objects/<sha256>.blob` — содержимое; `snapshots/<id>.json` — версия формата, время, относительные пути, хеши и размеры. Манифест публикуется переименованием временного файла после завершения копирования. Объекты неизменяемы при обычной работе приложения.

Snapshot удерживает эксклюзивный file-lock. Ограниченный Parallel.ForEachAsync читает исходники и пишет временные объекты; одинаковые хеши объединяются. Перед повторным использованием объекта проверяются размер и SHA-256. Ошибка любого работника не публикует снимок, но может оставить неиспользуемые объекты.

Restore сначала проверяет манифест, пустоту назначения и целостность всех объектов. Без --apply ничего не создаёт. После согласия копирует файлы с CreateNew, не перезаписывая имеющиеся. Это не транзакция файловой системы: прерывание оставляет частично восстановленную папку. Не допускается внешнее изменение каталогов во время операции.

Тесты покрывают дедупликацию, diff, round-trip, dry-run, отказ при повреждении объектов, непустое назначение и traversal в манифесте. Будущее развитие: блоковое хранение больших файлов, журнал операций, шифрование и retention-политики.
